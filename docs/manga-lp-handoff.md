## 他のAIへ最初に伝えること

以下をそのまま指示文として使用してください。

> `publish/index.html` を編集してください。漫画画像、漫画の表示順、`.comic` 要素、漫画間の `.bridge` は変更しないでください。編集対象は、最後の漫画画像直後にある `<div class="lp-content">` から下のLP本文です。既存のコピー意図、必須事実、相対画像パス、スマホ対応、固定CTAを維持してください。変更案を出すだけでなく、HTML/CSSへ直接反映してください。

## 編集対象ファイル

- LP原本：`publish/index.html`
- 公開ページへの組み込み：`src/app/page.tsx`
- 公開用漫画画像：`public/src/01.jpg`〜`public/src/09.jpg`

`src/app/page.tsx` は `publish/index.html` のCSSとbodyを読み込んでトップページに表示しています。通常、デザインやコピーの変更は `publish/index.html` だけで完結します。

## 変更してはいけない範囲

- `src/01.jpg`〜`src/09.jpg` の順番とファイル名
- `<img class="comic">` で始まる漫画9枚
- 漫画間の `.bridge`
- 相対画像パス
- CTAのリンク先

LP本文の開始位置は次の要素です。

```html

```

## LPの目的

「LP制作サービス」を売り込むのではなく、読者に次の変化を理解してもらうこと。

- 毎回同じ説明をする状態から抜け出す
- 説明が終わった状態から会話を始める
- 営業を「説明」ではなく「質問に答える仕事」へ変える
- 最後に「無料デモを見る」を押してもらう

## 読者心理と7セクション

1. 「これ、自分のことかも」
2. 「でも本当にそんな風になる？」
3. 「LPで変わるの？」
4. 「高そう」
5. 「この人、信用できる？」
6. 「失敗したくない。でも気になる」
7. 「見てみようかな」

各セクションは1メッセージに絞り、説明資料ではなく読者の脳内会話として読める短文にします。

## 必ず維持する思想

- 欲しいのはLPではなく、毎回同じ説明をしなくていい状態
- LPは説明を代わりにしてくれる営業マン
- 営業の価値は説明ではなく、質問に答えること
- 説明が終わった状態から会話が始まると、営業の質が変わる
- 「いらない」という結論も尊重する
- 「自分の場合は？」という質問が生まれた時点でLPは成功

## デザイン方針

- 漫画の余韻を壊さない
- 背景：白〜薄い生成り
- 基本文字色：濃紺 `#2D3A4A`
- CTA：黄色〜山吹色のグラデーション
- 見出し：短く強く
- 本文：短文・改行多め
- 余白：広め
- スマホ最優先
- 1セクション1メッセージ

主なCSSクラス：

- `.lp-content`：LP本文全体
- `.lp-section`：各セクション
- `.thought`：読者の心の声
- `.lp-heading`：見出し
- `.lp-copy`：本文
- `.key-message`：要点
- `.price-grid`：価格表示
- `.facts`：信頼材料
- `.demo-box`：無料デモ説明
- `.final-section`：最終CTAセクション
- `.floating-cta`：画面下部の固定CTA
